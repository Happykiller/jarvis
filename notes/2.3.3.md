# Jarvis 2.3.3 - premiere release publique

La premiere version distribuee de Jarvis 2.x : le launcher Tauri qui demarre tout
l'environnement Galakrond depuis une seule fenetre, avec un dashboard qui suit
l'etat reel de chaque service.

## Ce que fait cette version

- **Demarrage 1-clic** de tout le stack : preflight WSL/Docker, `git pull`
  parallele, phases Docker ordonnees (infrastructure -> mail -> api -> frontends)
  avec attente de sante entre les phases, puis lancement de VS Code, MongoDB
  Compass et Chrome une fois les services HTTP-prets.
- **Boot resilient** : un service non critique qui echoue (mailcatcher, un
  frontend...) n'abat plus le boot - demarrage degrade, les apps se lancent quand
  meme.
- **Dashboard live** : une carte par service (etat HTTP/conteneur/TCP, port,
  latence), clic pour ouvrir l'URL, et **redemarrage par service** sans tout
  rebooter.
- **Journaux integres** : chaque boot/redemarrage est enregistre (30 derniers,
  horodates) et relisible dans l'application.
- **Barre des taches** : reduction dans le tray a la fermeture, instance unique,
  bascule "Lancer au demarrage".

## Depuis les toutes dernieres iterations

- **Plus de fenetre Windows Terminal** au demarrage (fini les onglets Claude +
  vierge).
- **Onglets Chrome dedupliques** : Mailcatcher ne s'ouvre plus en double.
- **Dependances a jour** pour la stabilite : Vite 8, React 19.2, framer-motion 12,
  Tailwind 4.3, et ~93 crates Rust au dernier compatible.

## Installer

Voir le tableau en bas : `Jarvis-2.3.3-x64-setup.exe` (le plus simple) ou le
`.msi`. Le paquet n'est pas signe - verifiez l'empreinte SHA256 ci-dessous avant
de lancer.
