# Base de connaissance — Jarvis

Mémoire longue du projet **Jarvis** : le launcher desktop (Tauri + React) qui
démarre l'environnement de dev **Galakrond** sous WSL2. On y écrit le *pourquoi*,
les invariants et les décisions ; le *comment* reste dans le code.

Cette KB est en français, versionnée, et lue par Claude via
[`CLAUDE.md`](../../CLAUDE.md).

## Entrées

- **[DAT/](DAT/README.md)** — Dossier d'Architecture Technique : stack, arborescence,
  environnements, et une fiche par composant (orchestrateur, santé, lanceurs, tray, logs, config).
- **[DAF/](DAF/README.md)** — Dossier d'Architecture Fonctionnelle : ce que Jarvis fait
  pour son utilisateur (démarrer l'environnement, superviser les services, se distribuer).
- **[REGLES/](REGLES/README.md)** — process, workflows, consignes, normes et lois du projet.
- **[MOTEUR.md](MOTEUR.md)** — cartographie du cerveau moteur (`.claude/` : skills, agents, hooks, MCP).
- **[HISTORY.md](HISTORY.md)** — index chronologique des sujets abordés.
- **[BACKLOG.md](BACKLOG.md)** — roadmap et pistes décidées mais pas encore faites.
